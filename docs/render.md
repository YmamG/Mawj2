# نشر Mawj2 على Render

تستخدم هذه الطريقة خدمة ويب Django، وقاعدة PostgreSQL دائمة، وقرصًا دائمًا لصور الحسابات والأهداف. ملف `render.yaml` في جذر المشروع يعرّف المكونات وإعداداتها الآمنة. تعرض Render التكلفة والخطة المتاحة قبل إنشاء الموارد؛ اختر خطة تدعم **Persistent Disk** حتى لا تضيع الصور عند إعادة التشغيل.

## 1. إنشاء Blueprint

1. سجّل الدخول إلى [Render](https://render.com/) باستخدام GitHub.
2. من **Dashboard** اختر **New +** ثم **Blueprint**.
3. اختر المستودع `YmamG/Mawj2` وامنح Render صلاحية قراءة هذا المستودع فقط إن أمكن.
4. تأكد أن اسم ملف Blueprint هو `render.yaml` ثم اضغط **Apply**.
5. راجع الموارد قبل التأكيد: خدمة ويب `mawj2`، قاعدة بيانات `mawj2-db`، وقرص `mawj2-media` بحجم 1 GB.

ينشئ Blueprint قيمتي `DJANGO_SECRET_KEY` و`MAWJ_JOURNAL_KEY` عشوائيًا داخل Render. لا تنسخهما إلى GitHub، ولا تغيّر `MAWJ_JOURNAL_KEY` بعد وجود يوميات مشفّرة لأن المفتاح مطلوب لفتحها.

## 2. انتظار أول نشر

ينفذ Render تلقائيًا:

```text
bash scripts/render_build.sh
bash scripts/render_start.sh
```

الأول يثبت الحزم ويجمع CSS وJavaScript. الثاني يطبق migrations على PostgreSQL ثم يشغّل Gunicorn. عند ظهور **Live** افتح الرابط الذي ينتهي بـ `.onrender.com`.

## 3. اختبار النشر

1. افتح الصفحة الرئيسية وتأكد من ظهور التنسيق.
2. أنشئ حسابًا تجريبيًا وسجّل الدخول.
3. أضف مهمة وتدوينة، ثم ارفع صورة تجريبية للملف الشخصي.
4. من Render اختر **Manual Deploy → Deploy latest commit** أو أعد تشغيل الخدمة.
5. سجّل الدخول مرة أخرى وتأكد أن الحساب والمهمة والتدوينة والصورة ما زالت موجودة.

إذا فشل النشر، افتح **Logs** في خدمة `mawj2` وابحث عن أول سطر أحمر. لا ترسل مفاتيح البيئة أو عنوان `DATABASE_URL` عند مشاركة الخطأ.

## 4. الذكاء الاصطناعي

يبدأ الموقع بوضع `demo` الذي لا يحتاج مفتاحًا خارجيًا. لتفعيل Gemini لاحقًا، أضف في **Environment** داخل خدمة الويب:

```text
AI_PROVIDER=gemini
GEMINI_API_KEY=المفتاح_الخاص
GEMINI_MODEL=auto
```

احفظ القيم ثم أعد النشر. لا تضع المفتاح في `.env.example` أو GitHub.

## 5. التحديثات التالية

عند رفع commit جديد إلى `main` يستطيع Render نشره تلقائيًا. قاعدة PostgreSQL والقرص الدائم لا يُستبدلان مع نشر الكود. قبل حذف أي مورد أو تغيير مفتاح اليوميات، خذ نسخة احتياطية من البيانات.
